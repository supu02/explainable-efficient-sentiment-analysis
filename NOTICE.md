# Project provenance and reuse

The report credits **Simo Berrada Rekhami and Supriya Malla** for the Explainable AI course project, 2025–26. This portfolio is derived from the supplied `green-ai-efficient-nlp-main` project and its report. The earlier Green AI code contains contributions from a broader team; the portfolio preserves that provenance and does not claim exclusive authorship of the inherited model code.

The source project did not supply a project-level software license. This packaging does not assign a new license or change contributors' rights. Third-party libraries, the pretrained TinyBERT model, the IMDb reviews, and the supplied conference style retain their respective terms and attribution requirements.

The source archive contains the active experiment and supporting evidence. Earlier experimental variants, personal development logs, and stale results remain in the original workspace rather than this portfolio. The report copy has been edited to align figure captions and interpretation with the saved clean evaluation results.

Portfolio additions include a prediction CLI, portable TinyBERT architecture loading, generated figures, documented artifact hashes, rerun output separation, and lightweight verification. They do not constitute retraining or a new benchmark experiment.
